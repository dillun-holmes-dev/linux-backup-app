## Reporting a Vulnerability

If you believe you have found a security issue in VaultLeaf Backup:

- **Do not** publicly disclose the vulnerability in issues, discussions, or
  pull requests before it has been triaged.
- Use **private vulnerability reporting** — the report is only visible to
  you and the repository maintainers.

### How to report (step by step)

1. Go to the repository page:
   <https://github.com/dillun-holmes-dev/linux-backup-app>
2. Click the **Security** tab (in the tab bar below the repo name).
3. Click the **Report a vulnerability** button (top-right, blue button).
4. Fill in the report form:
   - **Title** — a short summary of the issue.
   - **Description** — as much detail as you can: affected version, steps to
     reproduce, and potential impact.
   - **Attach files** (optional) — you can add a proof of concept, logs, or
     screenshots.
5. Click **Submit report**.

Your report is **private** — only you and the repository maintainers can see
it. After submitting you can add a comment with more details, and you can
later request a **CVE** for the vulnerability if you want one.

Given this is a community project with no formal security team, please allow
time for a response. Reports will be acknowledged as best as possible, but
there is **no guarantee** of fixes, timelines, or that all reported issues
will be addressed.
